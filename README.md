## Dashboard Features

- **Monthly Analysis:** Revenue and profit trends.
- **Country Analysis:** Top 5 countries by revenue.
- **Sales Channels:** Revenue share by channel.
- **Regional Analysis:** Revenue distribution across regions.
- **Profitability Map:** Country-wise profit performance.
- **Interactive Filters:** Category, quarter, and country slicers.

## Tools Used

Microsoft Excel | PivotTables | PivotCharts | Slicers | Data Visualization
